# ADR-0002: Privilege seam — all privileged kernel entries stay greppable behind one boundary

## Status

Accepted (reconstructed from the tree — see Provenance).

## Context

KryProbe backends observe the kernel through BPF load, attach, and
inspection. The architecture plans a future broker boundary: the
modules that touch the kernel directly will one day move across it.
Until then, privileged entries must stay identifiable and contained,
or reviewers cannot tell which code paths need privilege to reason
about them.

## Decision

Two rules, both fail-closed and enforced by `cargo xtask check`
(`xtask/src/seam.rs`):

- **Rule A (raw entry):** `libc::syscall(` call sites exist only in
  the allowlisted files — the `bpf()` wrapper, `pidfd_open`, and
  the token mount flow. A new raw entry point anywhere else fails
  the gate.
- **Rule B (containment):** outside `crates/kryprobe-privilege/`,
  the only `libc::name(` calls are benign identity getters
  (`geteuid`, `getegid`, `getpid`, `getppid`, plus per-file
  exceptions for unprivileged fixture I/O). Backends, core, CLI,
  and report code perform no privileged syscalls, directly or
  otherwise. Euid checks and errno classification live behind the
  seam (`kryprobe-privilege/src/host.rs`); the CLI renders typed
  outcomes without inventing errnos.

## Consequences

Positive:

- The broker boundary is greppable today: moving the seam later is
  a file move, not an audit.
- Privilege reviews have a mechanical gate instead of folklore.

Negative:

- Legitimate new kernel entries require an allowlist edit plus a
  reason — deliberate friction, recorded in the seam module.
- The gate scans text, not semantics: genuinely unprivileged new
  `libc` uses outside privilege still need per-file exceptions.

## Enforcement

`xtask check` runs the seam gate before fmt/clippy/tests
(`+ seam: privilege boundary holds`). Comment/literal scrubbing
keeps the scan honest (a call name inside a comment must not trip
the gate; a `//` inside a string must not hide a real call).

## Provenance

No ADR file shipped with the tree; this record reconstructs the
decision from its enforcement (`xtask/src/seam.rs`) and its
citation sites (`cmd_token.rs`, `runtime_facts.rs`, `host.rs`,
`filecaps.rs`, `token/mint.rs`, `token/spawn.rs`). The rules above
are the gate's behavior, not an aspiration — if the gate and this
file ever disagree, the gate wins and this file must be amended.
