# ADR-0013: Per-program BPF lanes + universal kernel-miss surfacing

## Status

Accepted (M1 Task 06, 2026-10-12). Amends the BPF/userspace lane
contract; re-proves ADR-0009 under per-program lanes. Sealed M1
evidence (ADR-0016 verdict NO-GO) is unaffected — this ADR governs
new bytes only, never a re-judgment.

## Context

FORENSICS-2 (M1 Task 05 record, 2026-10-12) proved two exactness
defects on the frozen bytes:

1. **Trampoline guard skips.** `truth − ΣKCTX = miss_delta` holds
   EXACT on 51/51 sealed n_cgroup M legs (truth = 2·ops+64):
   the shortfall is kernel-side non-execution (guard busy →
   skip), never userspace fold loss (lanes balanced 22–27%,
   `KDROPS` zero). But the miss terminal surfaced ONLY in
   workload-mode reports — api-returns legs carried
   `uncovered:kernel_delivery_unmeasured` with no count.
2. **`KTOT` shared-slot race.** `KTOT` was one `PerCpuArray<VAgg>`
   slot updated by all 9 fexit programs with plain load/store
   (`update_slot`; no BPF atomic RMW exists on this target).
   Two programs interleaving on one CPU lost increments:
   `ΣKCTX − KTOT` lag on EVERY sealed 1M n_cgroup leg
   (41–189 calls) and ~1/3 of 4K legs (max 821). Same race
   shape in `KCTLCOUNT` (fence count), the 8 `KDROPS` sites,
   and `KCTX_DROPS` (all single-slot, all writers shared).

## Decision

### (a) One slot per program (ordinals 0–8, declaration order)

`KTOT`, `KCTLCOUNT`, `KCTX_DROPS`: `max_entries` 1 → 9, indexed
by program ordinal. `KDROPS`: 8 → 72, slot = ordinal × 8 + site.
Ordinals (`KPROG_ALLOC` … `KPROG_FINUP`, `N_KPROGS = 9`) live in
`kryprobe-abi` with a GPL-2.0-safe twin in `kcrypto.rs`, pinned
by `kprog_lanes.rs` (values + `max_entries` expressions).

Exclusivity argument (replaces the ADR-0009 shared-slot claim):
the trampoline guard serializes each program against itself per
CPU — a reentrant same-program entry SKIPS instead of racing —
and distinct programs touch disjoint slots. No two writers ever
share a (slot, lane) pair, so plain load/store is exact without
atomics. Preemption cannot break it: a preempted writer's slot is
untouched by whoever runs next (same program → guard skip;
different program → different slot).

Userspace folds all slots × lanes (sums; checked variants keep
their `EOVERFLOW` refusal). `KCTLCLOSED` stays single (read-only
after close — no race). `KIDN` saturating diagnostics stay shared
by design (flag semantics, out of the exactness equations).

### (b) Misses in every report format

`drive_session_inner` reads the miss terminal post-fence for
api-returns legs (workload mode keeps its own read; never
double-read) and feeds `SessionMeasurements.kernel_misses`:
`Some(m)` renders an exact `kernel_misses` counter (and flips
`aggregate_counts` to `Partial` when m > 0); `None` keeps the
`uncovered:kernel_delivery_unmeasured` reason. The miss telemetry
line prints for api-returns too (same v1 shape as workload).

Exact-count claims now require a clean (`0`) misses read —
absence claims stay inconclusive (completion unobserved).

### (c) ADR-0009 re-proof under per-program lanes

ADR-0009's increment-then-check stands, with the count split
across 9 slots: admission/release touch only the entrant's
ordinal slot; the drain requires ALL slots × lanes at zero. A
stuck writer blocks quiescence in its own slot exactly as before
— splitting changes no verdict, it only removes the lost-update
race that could previously FAKE a zero (an increment lost to a
concurrent decrement on the shared lane). Fence receipt semantics
(`Quiescent`/`Pending`) are unchanged.

## Consequences

- New BPF object bytes (map dims change) → new pins; old sealed
  cells are unreadable by new userspace folds ONLY in the sense
  that old objects lack the slots (lookup fails loud, never
  misfolds — slot-0 `ENOENT` keeps its healthy-absent rule).
- Telemetry `occupancy.ktot`/`kdrops_slots` now emit true slot
  counts (9/72); consumers treat them as construction facts.
- Regression gate (Task 06): n_cgroup 4K+1M legs must show
  truth−ΣKCTX=misses, `KTOT`=ΣKAGG=ΣKCTX, fence lanes 0, and
  `kernel_misses` in api-returns coverage.
- Residual R1 (set-40 md legs 02B/03B ~2000-call gap, sealed,
  INVALID) and the 16/16-A-side timeout correlation stay open
  as bounded non-blocking items — neither is explained by this
  ADR, neither blocks it.
